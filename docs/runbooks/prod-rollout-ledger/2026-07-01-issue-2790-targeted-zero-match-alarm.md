# 2026-07-01 · Issue #2790 · targeted revocation zero-match alarm

Adds the fleet-wide `revocation-targeted-zero-match` CloudWatch metric-math alarm for qURL v2 targeted revocation. The alarm watches `RevocationTargetedZeroMatch >= 1` while `RevocationFanoutSent{FanoutMode=targeted} < 1` in the same 5-minute window, which is the all-or-nothing `target_ac_ids` ↔ `ACConn.ACId` identifier-drift signature from #2790. The same shape can also mean every named target AC was disconnected fleet-wide, so the single-window page is intentional fail-loud triage rather than proof of drift by itself. This is additive monitoring; it stays `INSUFFICIENT_DATA`/not-breaching until qurl-service emits targeted revocation events.
