# 2026-06-18 · PR #2681 · Relay backend TLS

- **Owner:** prod rollout coordinator
- **Source:** [PR #2681](https://github.com/layervai/nhp/pull/2681), [issue #2663](https://github.com/layervai/nhp/issues/2663)

Roll the relay ALB target group and relay launch template onto HTTPS backend traffic, then verify the fleet is healthy before treating the encrypted backend path as live. Sandbox has relay enabled today, so merge/apply immediately swaps the relay listener/ASG attachment to a new HTTPS target group. The existing plaintext relay instances stay in place until the new HTTPS health check marks them unhealthy, then convergence relies on ELB-health-driven ASG churn. Expect a multi-minute zero-healthy-target window on the sandbox relay endpoint until replacements pass health. Prod relay is still dark today (`deploy_relay = false`), so prod exposure is a future rollout concern when a later change flips prod relay on.
